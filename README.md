# 日本传统工艺综合档案 · Traditional Crafts of Japan

一个**单文件、零依赖**的中英日三语交互档案，收录日本经济产业大臣指定的传统工艺品与「人间国宝」（重要无形文化财保持者）。

- 或点击本 README 同级相对链接：[index.html](./index.html)

## 功能

- **三视图切换**：地理地图 / 工艺数据库 / 匠人档案
- **三语一键切换**：中文 · English · 日本語（界面与数据同步）
- **三轴联动筛选**：按地区 / 品类 / 匠人检索，地图与列表实时联动
- **匠人深档**：21 位人间国宝可展开卡片，含生平 · 师承谱系 · 代表作品

## 数据规模

- 工艺：**241 项**（METI 都道府県别指定全量名单，覆盖 47 都道府県、9 大地区）
- 匠人：**21 位**重要无形文化财保持者（代表性示例，非全量）

## 技术

纯 `index.html`（内联 CSS/JS，无外部依赖、无构建步骤）。浅底日系极简风格，可直接双击打开，或由任意静态服务器托管。

## 数据来源与声明

- 工艺清单：一般財団法人 伝統的工芸品産業振興協会 / 経済産業省（METI）
- 匠人名单：文化庁公开资料（代表性示例，非全量）
- 本档案为艺术 / 研究向的整理与可视化，数据如有出入以官方公布为准。
